# robertocinetto.com

One statically rendered marketing page for a freelance developer. Next.js 16 App Router, React 19,
Tailwind v4, TypeScript. No CMS, no database, no client-side data fetching. Around 1,600 lines of
source in total, so almost any change touches something documented below.

## Before you change anything

These are invariants, not preferences. Each links to the file that explains it.

- **All copy lives in `src/content/`.** Section components hold no copy of their own — not even a
  heading. [content-and-voice.md](docs/content-and-voice.md)
- **Server components only.** There is no `"use client"` anywhere in this repo. Adding the first one
  is an architectural decision, not a detail. [architecture.md](docs/architecture.md)
- **Design tokens only.** Never an arbitrary colour; spacing comes from the scale.
  [design-system.md](docs/design-system.md)
- **Radius is `0` everywhere except the portrait, and there are no shadows at all.** The accent colour
  never covers more than about 2% of the page. [design-system.md](docs/design-system.md#the-visual-law)
- **Read [gotchas.md](docs/gotchas.md) before editing `src/app/globals.css`.** It contains a
  specificity trap that silently drops every heading to weight 400.
- **Em dashes are used sparingly in page copy.** Prefer commas, then parentheses.
  [content-and-voice.md](docs/content-and-voice.md#punctuation)
- **Every number on the page is a measured result from a shipped project**, and work is anonymised —
  no client names, logos or screenshots. [content-and-voice.md](docs/content-and-voice.md)
- **This repo is public.** Never commit identifiers, `.vercel/`, or any `.env` file.
- **Pushing to `main` deploys to production.** There is no staging environment.
  [operations.md](docs/operations.md)

Before handing work back: `pnpm lint`, `npx tsc --noEmit`, `pnpm build`. There is no test suite and no
typecheck script.

## Two habits that keep this repo tidy

**Comments here explain decisions, not syntax.** The existing prose comments are load-bearing
documentation — several constraints exist only in them. Match that density rather than stripping it.

**Every value lives in exactly one file.** A number, a token or a formula is stated once and linked to
from anywhere else that needs it. `docs/gotchas.md` restates *rules* deliberately, so that the file
stands alone as a pre-flight check, but never the numbers behind them.
